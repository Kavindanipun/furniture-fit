# Furniture Fit SEO Test

Free GitHub Pages experiment for validating US/UK search demand around furniture measuring and fit questions.

## Publish
1. Upload `index.html`, `style.css`, `app.js`, `robots.txt`, and `sitemap.xml` to the repository root.
2. GitHub → Settings → Pages.
3. Source: **Deploy from a branch**.
4. Branch: **main**, folder: **/(root)** → Save.
5. Wait for GitHub to provide the live URL.
6. Replace `SITE_URL` in `sitemap.xml` with the exact live URL.
7. Add the site to Google Search Console and request indexing.

## Important
The calculator is a simple rectangular screening tool, not a guarantee that an item can physically be maneuvered through a real delivery route.
